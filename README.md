# Font Freda Ride Studio — 02.2.4 TEST

Versión web QA, **independiente** de 02.2.3 y r4. Incorpora modelos 3D regionales de tevy.dev, el perfil original de Font Freda, cámaras, sonido y 12 marchas. Puedes probarla en modo demo sin rodillo. La MTB por pistas de tierra todavía no está incorporada a esta versión.

Esta compilación web funciona sin servidor de aplicaciones: las salidas quedan en el almacenamiento local del navegador y se puede descargar un archivo FIT para conservarlas y subirlas manualmente a Strava. **No sustituye la aplicación estable ni guarda directamente en la carpeta de Documentos del Mac.**

El código de origen procede de Serpentine de Chris Perkles (licencia MIT, ver `LICENSE`), con contribuciones de Font Freda; fuentes y atribuciones adicionales en `ATTRIBUTION.md`. Prueba sin garantía de hardware: validar T-SOX y Safari antes de una publicación estable.

No está asociada con Zwift ni con fabricantes de rodillos.
